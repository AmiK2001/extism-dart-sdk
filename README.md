# Extism Dart SDK

Dart wrapper of [Extism](https://github.com/extism/extism/tree/main) library.

## Dynamic library

Extism dynamic library is not provided and can be downloaded from [latest stable releases](https://github.com/extism/extism/releases).

Extism dynamic library location for each platform described in **\_findLibraryPath** function.

Supported platforms:

- Windows (x64_86)
- MacOS (aarch64, x64_86 should work too)
- Linux (Not tested yet, WIP)
- Android (WIP)
- iOS (WIP)
